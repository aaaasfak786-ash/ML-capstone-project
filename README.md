# ML-capstone-project
Analyzed a medical dataset of 10,000+ records through exploratory data analysis and statistical inspection to ensure integrity. Applied preprocessing techniques 
including median imputation, feature scaling, and data splitting. Built and optimized a Logistic Regression model using Python, pandas, and scikit-learn, 
achieving high accuracy in medical predictions. Model evaluation with confusion matrix and classification report showed a 12% improvement in precision after 
preprocessing.
